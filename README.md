# slogan-generator

## Project Overview
A Natural Language Processing (NLP) project that uses neural networks to generate business slogans and classify industries based on slogan text.

## Skills Demonstrated
- Python
- TensorFlow/Keras
- NumPy
- Pandas
- SpaCy
- Jupyter Notebook

## Features
1. Text data preprocessing and tokenisation
2. LSTM-based slogan generation model
3. Industry classification model
4. Training and evaluation on real-world slogan data
5. End-to-end NLP workflow combining text generation and classification
6. Performance comparison between generated slogans and classifier predictions
